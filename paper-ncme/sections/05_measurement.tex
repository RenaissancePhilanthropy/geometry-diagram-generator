\section{Why this matters for measurement}
\label{sec:measurement}

Seen through the lens of educational measurement, this is a way to write test items and score them automatically---at the same time.

Each template is an item generator. Fixing every parameter but one and sweeping that parameter---an angle through $30^\circ, 40^\circ, 50^\circ$, say---mints a family of structurally parallel questions, and the checker confirms each variant without anyone looking (\cref{fig:variants}). An author thus has an unlimited, refreshable supply from a single construction. These variants are parallel by construction; whether they are also of equal empirical difficulty---true psychometric isomorphs---is a calibration question we have not yet tested. And because the answer key is produced \emph{with} each item rather than written afterward, the most common source of scoring error---a key that has drifted away from the question---simply cannot happen. In the vocabulary of the field the template is an \emph{item model} \citep{gierl2012itemmodels}, now one that emits its own key. That move also shifts where quality control happens, in the way the item-generation literature recommends: rather than vetting every generated item, one reviews the construction logic that produces them all \citep{gierl2016review}.

The diagram a student (or a model) produces is a constructed response, and the same description that built the item can score it. Here a measurement audience should weigh two claims separately. The \emph{generation} claim is unconditional: because the key is computed with the item, it cannot drift from the question, and that key is a short, readable list of exactly what must be true (\cref{tab:predicates})---open to inspection rather than buried inside a holistic rubric. The \emph{scoring} claim has to be earned empirically, and our validity study (\cref{sec:scoring}) is candid that it is not yet earned: the auto-score agrees with human graders only moderately and errs in a single direction, so for now it is best read as a reliable upper bound on correctness---fit for benchmarking and for flagging likely-wrong work, but not yet for standalone high-stakes scoring. Closing that gap means tightening the soft keys that \cref{sec:scoring} pinpoints, which is in progress.

\paragraph{Scope.}
The version described here covers plane geometry. The same machinery should extend to coordinate graphs and 3D solids by adding new kinds of building block, though we have not built those yet. And where a topic has no natural template, an author can still write items and keys by hand and score them with the very same checker. The core idea stays simple: when a diagram is built from an exact description, that same description tells you whether the diagram is right.
