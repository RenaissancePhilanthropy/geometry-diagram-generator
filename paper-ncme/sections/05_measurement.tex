\section{Why this matters for measurement}
\label{sec:measurement}

Seen through the lens of educational measurement, this is a way to write test items and score them automatically---at the same time.

Each template is an item generator: one template stands for a whole family of equivalent questions, so an author has an unlimited, refreshable supply at a fixed level of difficulty. And because the answer key is produced \emph{with} each item rather than written afterward, the most common source of scoring error---a key that has drifted away from the question---simply cannot happen.

The diagram a student (or a model) produces is a constructed response, and the checker is its automatic scorer. Two points stand out for a measurement audience. First, the answer key is a short, readable list of exactly what must be true (\cref{tab:predicates}), so what the item measures is open to inspection rather than buried inside a holistic rubric. Second, we are candid about where the automatic score is soft: as \cref{sec:scoring} showed, it is currently too generous on items that add a construction, and tightening those keys is in progress.

\paragraph{Scope.}
The version described here covers plane geometry. The same machinery should extend to coordinate graphs and 3D solids by adding new kinds of building block, though we have not built those yet. And where a topic has no natural template, an author can still write items and keys by hand and grade them with the very same checker. The core idea stays simple: when a diagram is built from an exact description, that same description tells you whether the diagram is right.
