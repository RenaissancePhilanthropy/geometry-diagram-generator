How every number is computed

Companion to the Metacognition Brief (the findings, plain language) and the Methodology page (the four instruments). This page is the third leaf: for each figure we report, the formula that defines it and the recipe that produces it — so any number can be re-derived from the stored records.

16 cells = 4 models × 4 benchmarks
750 records/cell = 150 q × 5 attempts
read depth fixed at 0.7·L
all scores out-of-fold

The atom one graded record

Everything below is arithmetic over one stored object

Each of the 12,000 records holds: the residual-stream vector h ∈ ℝd at the confidence decision token (turn 3, the position about to emit "Confidence: N") at every layer; the same read at the last prompt token (before any output — the PRE site); the model's stated confidence N ∈ [0,100]; its P(True) bet; and the external grader's verdict y ∈ {0,1} — never shown to the model.

The ruler used by every result

AUROC — can this reader rank right above wrong?

AUROC = Pr(s+ > s−) + ½·Pr(s+ = s−) = 1n+n− ∑i∈+ ∑j∈− [ 𝟙(si>sj) + ½·𝟙(si=sj) ]
recipe
  1. Any reader emits one scalar s per record (a stated number, a probability, a projection).
  2. Form every (correct, incorrect) pair in the cell; count how often the correct one scores higher; ties get half credit.

0.5 = coin flip · 1.0 = perfect. Rank-based, so a model that says "95" for everything is scored fairly (the tie term matters — stated confidence bunches hard at 95), and class imbalance (some cells are ~90% one class) doesn't distort it.

confidence intervals: bootstrap; resampled by question wherever records share a question

E1 internal vs stated · fig 1

Probe 0.57–0.95 vs stated 0.54–0.87 · probe wins 12/16

probe read sprobe = w⊤h̃,   h̃ = PCA(standardize(h0.7L)),   w = argmin ∑i ℓCE(σ(w⊤h̃i+b), yi)
recipe · per cell
  1. Split the 750 records into k folds grouped by question — a question's five attempts never straddle train/test.
  2. Fit standardize → PCA → logistic regression on the train folds; score the held-out fold; concatenate all out-of-fold scores.
  3. AUROC of those scores = the internal bar. AUROC of the stated numbers on the same 750 records = the spoken bar. Same ruler, only the scorer changes.

read at fixed 0.7·L — never the best-scoring layer · exceptions: 3 losses (small-n, 2 on Gemma-4) + 1 tie

gapcell = AUROCprobe − AUROCstated   →   barbench = 14 ∑models gapcell
recipe
  1. Subtract the two E1 bars per cell; group the 16 gaps by benchmark; bar = mean over the 4 models, one dot per model.

Geometry's small gap is compression, not absence: at 13–39% pass, failure is near-default, which shrinks every reader's contrast.

Read-site check layer sweep · fig 5

Chance at layer 0 → ~0.8 mid-late: the signal is computed

recipe
  1. Save h at the decision token at every layer ℓ.
  2. Run the full E1 probe pipeline per layer (same folds, same labels); plot out-of-fold AUROC against relative depth ℓ/L.
  3. Layer 0 is the falsifier: the wording at that token is identical for every record, so a layer-0 read above chance would mean surface leakage. Measured: ≈ 0.5.

This check has drawn blood: our first read site (the answer tokens) decoded at 0.74 at layer 0 — pure surface cues — and was scrapped.

Pre vs post two read sites · fig 6

Difficulty and self-assessment are different directions

transfer = AUROC(wPOST⊤hPRE) = 0.39–0.67
recipe
  1. PRE = read at the last prompt token (question seen, nothing written — no elicitation). POST = the turn-3 decision token. Identical pipeline, labels, and folds; only the read site changes.
  2. Layer curves per site: POST rises above PRE by mid-depth in all four models (geometry summary: POST 0.66–0.70 vs PRE 0.52–0.62).
  3. Transfer: apply the POST-trained direction to the PRE site. Low transfer (0.39–0.67) = largely distinct directions — "this looks hard" ≠ "that attempt worked". Residualizing POST on PRE keeps 0.59–0.87.

E2 difficulty control · fig 3

Difficulty frozen: probe 0.89 vs P(True) 0.48

AUROCwithin = 1|Qmix| ∑q∈Qmix AUROC(records of q)
recipe
  1. Keep only mixed-outcome questions: same model, same question, some of the 5 attempts pass and some fail.
  2. Compute AUROC inside each such question — difficulty is constant there by construction — then average across questions.
  3. Baseline P(True): branch off after the attempt, ask "is your answer correct — True or False?", read the probability mass on the True token.
  4. Bootstrap resamples questions, not records, to respect the grouping.

Anything above 0.5 here is per-attempt information — topic difficulty cannot explain it. Headline cell: GLM×MATH, n=36 mixed questions.

E3 label-free lens

Zero labels, same signal: 0.76–0.88 on dense models

Jℓ = 𝔼text[ ∂hL∂hℓ ]    rw = Jℓ⊤uw    slens = (r̄fail − r̄ok)⊤h
recipe
  1. Fit the transport map Jℓ (Anthropic's Jacobian lens) on ~500 generic prompts — backward passes accumulating the expectation. No task data, no labels, ever.
  2. Collapse each word to one readout vector rw; average over the failure family {wrong, incorrect, error, mistake, false, flawed} minus the success family {correct, right, true, valid, accurate}.
  3. Score every stored snapshot with one dot product; AUROC against the grader, same ruler as E1.

The failure fingerprint (E4): the collapse metric is cos(r̄ok, r̄fail) — dense ≈ 0.4 (directions distinct), MoE ≈ 0.96 (the lens can no longer tell its own two word-families apart). Averaged transport can miss signal, never hallucinate it — a null is "not in the typical verbalizable subspace", not "absent".

validated by reproducing held-out logits + hard top-k check against the package's own lens.apply

E5 steering · fig 4

Wrong-answer confidence 80 → 43 · ECE 0.31 → 0.13

amplifyh ↦ h + (g−1)(v̂⊤h − μ)v̂,   μ = 𝔼[v̂⊤h]   (exact no-op at g = 1 · no labels at intervention time)
ECE = ∑bins b nbN | acc(b) − conf(b) |
recipe
  1. During turn 3 only (the answer is already on the page), scale the record's own projection on v̂ by gain g ∈ {1, 2, 4}.
  2. Track mean stated confidence separately for wrong answers (80 → 65 → 43), correct answers (97 → 96 → 89), and a norm-matched random direction (flat).
  3. ECE before/after: bin stated confidence, compare each bin's claimed confidence to its actual accuracy — 0.31 → 0.13.
  4. Causal bar, all three required: effect grows with dose · random control flat · sign flip reverses it (dampening → more overconfident).

Same direction, injected during the attempt "toward correct": no accuracy lift (0.38 vs 0.41 baseline, GLM×GPQA — preliminary). A gauge the model reads, not a wheel that drives the answer.

causal on Mistral×MATH · GLM null at tested settings (stated confidence saturates ~100) · Gemma×GPQA rerun queued

Conventions every number above inherits these

Fixed depth: all reported reads at 0.7·L (or a [0.5L, 0.9L] band mean) — never max-over-layers. Out-of-fold: no score is ever computed on records its reader was fitted on; folds are grouped by question. Bootstrap: CIs resample questions where records share a question. One seed per cell: CIs cover item sampling, not seed variance — an honest limit, on the record.
