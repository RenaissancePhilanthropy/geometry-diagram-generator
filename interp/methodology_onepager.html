Reading & steering a language model's internal correctness signal

Methodology, one page — math with plain-English translations under every equation.

the one idea
a concept is a direction u  ·  read = u⊤h  ·  write = h + αu
reading = measure how much a thought points along a direction · writing = nudge the thought along it
how to read the symbols
hthe model's thought = a long list of numbers
u⊤h"overlap": how much thought h points along direction u (one number)
𝔼[·]"the average of …"
∑"add up over …"
σ(z)squashes any number into a probability (0–1)
WUthe unembedding: turns a thought into a score per word
v̂the direction v, shrunk to length 1
ythe true answer: 1 = correct, 0 = wrong

Setup

hℓ+1 = hℓ + fℓ(hℓ)     logits = WUhL
▸ In plain words: each layer adds its edits to a running "thought" vector; at the end, the unembedding turns the final thought into a score for every possible next word.

We read the thought at the confidence token — the spot where the model is about to say its confidence number. Same context every time, so nothing about the problem leaks in from the raw tokens; any signal there was genuinely computed. The right/wrong label comes from an outside grader the model never sees.

1 · Probe — reading the signal (using the answer key)

Pr(y=1 | h) = σ(w⊤h̃ + b),    σ(z) = 11 + e−z
▸ In plain words: measure how much the thought points along a learned "correctness" direction w, then squash that into a probability the answer is right.
v = h̄ok − h̄fail
▸ In plain words: the simplest way to get that direction — the average "correct" thought minus the average "wrong" thought: an arrow pointing from wrong toward right. (Training a logistic-regression classifier gives a sharper version of the same arrow.)

We train on some questions and test on different ones (so it can't memorize a question), and report the reading at a fixed mid-to-late layer — not the single best-looking layer.

2 · Scoring — how we grade any reader

AUROC = 1n+n− ∑i∈+ ∑j∈− 𝟙[si > sj]
▸ In plain words: grab one correct and one incorrect answer at random — how often does the reader score the correct one higher? 0.5 = coin flip, 1.0 = perfect. (Rank-based, so it's fair even when the model pins its stated confidence at 95.) A separate number, ECE, measures how far the stated confidence is from the true accuracy.

3 · Jacobian lens — reading it without the answer key

Jℓ = 𝔼 [ ∂hL∂hℓ ]     lensℓ(h) = WU(Jℓh)
▸ In plain words: a mid-layer thought isn't in "word language" yet. So we learn a translator Jℓ by asking "if I nudge the thought here, how does the final output move?", averaged over lots of ordinary text. Run a thought through the translator, look it up in the word-dictionary → which words it's leaning toward saying.
sjlens = (r̄fail − r̄ok)⊤h    with   rw = Jℓ⊤uw
▸ In plain words: our signal = how much the thought leans toward failure words ("wrong", "error") minus success words. It never saw the answer key, so if it agrees with the probe, the signal is real — and it tells us whether the "I'm wrong" thought reaches the part that can speak.

4 · Steering — proving the model uses the signal

addh ↦ h + αv
amplifyh ↦ h + (g−1)(v̂⊤h − μ)v̂
▸ In plain words: reading only shows the signal is there. To show it's used, we write it back in while the model answers. Add: push the thought along the correctness direction by a dial α. Amplify: turn up the model's own existing amount of that direction, like a volume knob — using no answer key. It's causal if the stated confidence moves and a random direction of the same size does nothing.

Controls — each result must survive all of these

Read-site: at the raw-input layer the signal is ~chance (so it's computed, not copied from the words). Difficulty: it works even on the same question tried many times (not just "hard vs easy"). Surface: beats answer length/shape. No leakage: train and test never share a question. Causal: random-direction & answer-unchanged controls. Grader: checked the answer key itself is clean.

The whole toolkit, in one line:  read = u⊤h  (measure overlap with a direction),   write = h + αu  (nudge along it). The probe finds the direction with the answer key; diff-of-means is the crude version; the Jacobian lens finds it without the key; steering adds it back to prove the model uses it. Same arrow, four operations.
