Does the probe read meaning, or does it read format?

The spatial probes were trained on one model writing one format. This experiment holds the figure fixed, varies only the surface format it is written in, and asks whether a frozen probe still reads the geometry. Sibling page to the Metacognition Brief; everything here is re-derivable from interp/transfer/.

The atom one captured position

Same figure, four texts, one label

Each figure is generated parametrically (no LLM), compiled through the real pipeline (validate → lower → compile → check), and rendered as recipe JSON, TikZ, SVG source, and English prose. A record is the residual-stream vector h ∈ ℝ1536 at an entity-name token (all 29 states), captured in a plain forward pass — no generation. Its label comes from the compiled SymPy geometry, never from the text: the entity's relation (midpoint, tangent, …, 8 classes), its bbox-normalized position, or its vertex angle. Names are random letters, so the name token itself carries ~nothing.

The probe why "frozen" is well-defined

Scaler, PCA, and head collapse into one affine map

one map s(h) = w⊤P⊤ diag(1/σ)(h − μ) + b   (μ, σ, P, w, b all fit on recipe-train, then never touched)
recipe
  1. Fit standardize → PCA(100) → linear (logistic / ridge) on recipe-format activations of the train figures only.
  2. At test time nothing is refit — the target format's activations are pushed through the stored μ, σ, projection P, and weights. The PCA "at test time" is literally the same matrix.
  3. Because every step is affine, the probe is ultimately one set of directions in the raw 1536-dim stream; PCA acts only as a training-time regularizer confining w to recipe's top-100 variance subspace.

That confinement is a real caveat: a transfer failure can mean "different directions" or "directions outside recipe's top-100 subspace". The PCA-free and rotation-aligned controls below separate these.

The ruler used by every result

Transfer fraction — where between floor and ceiling does the frozen probe land?

transfer fraction = scorefrozen − floorceiling − floor
recipe · per (labeler, layer, target format)
  1. scorefrozen — recipe-trained probe on the target format, held-out figures (figure split shared across formats; held-out means held out everywhere).
  2. floor — predict the label from the token string alone (majority label per token on target-train). Names are randomized, so this sits near majority class.
  3. ceiling — identical pipeline trained natively on the target format, same split. For regression the ruler is R² against the ceiling (floor = 0 by construction).
  4. 1.0 = the recipe directions read the target format as well as its own probe · 0 = nothing beyond naming.

Outside the band, frozen probes fall to floor (classification) or strongly negative R² (regression). Early layers are token-bound; late layers re-encode format-specifically. The shared subspace lives exactly where the 7B study localized its computed representations (mid-late network) — a convergence worth testing at scale.

R4 vertex angle · null

Angle is not linearly readable in reading mode — in any format

In-domain peak R² = −0.03; native ceilings ≈ 0 across all four formats. Transfer is undefined when there is nothing to transfer. Consistent with the leak-free correction in the main RESULTS.md, where angle was already unsupported.

Conventions & caveats every number above inherits these

Pilot model: 1.5B (7B does not fit this machine); probes are model-specific — the 7B/32B rerun is a GPU-box job, scripts unchanged. Template coupling: 8 templates make relation ≈ (construction type × slot); absolute accuracies are inflated, cross-format contrasts are not (same figures everywhere). Coordinate clustering: bbox-normalized positions cluster by template role — read in-domain R² 0.91 accordingly. Reading ≠ generation: original probes trained on self-generated text; the bridge condition needs the old GPU-box captures. One English style: fixed sentence templates; paraphrase robustness untested.
